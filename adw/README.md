## 阅读顺序

1. 先看 [MODS.md](MODS.md) 第 0 节的分层原则：部署层 → 包层 → 框架层，能不动框架就不动。
2. 再看 [PROJECT.md](PROJECT.md) 的第 1 节，理解 Core / Persona / Memory / World 各管什么。
3. 想看某个行为是怎么做出来的，按 MODS 的主题找条目，条目里写了实现位置。
